HOW WE WILL DOCUMENT CODES

  • Exact input sequence or in-game phone number.
  • Platform tested: PlayStation 5 or Xbox Series X|S.
  • Effect and any duration or limitations.
  • Whether using the code affects trophies, achievements or mission progress, if verified.
  • Last-tested game version and date.

We will keep platform-specific inputs separate and label any code that is unconfirmed or community-reported. Nothing will be presented as tested until it has been tested.

OUR STANDARD: This page distinguishes official Rockstar information from information that has not yet been confirmed. We will update it as we verify details in-game and against reliable sources.
