# The GTA Guide

An independent fan-made field guide to Grand Theft Auto VI.

## Project goals
- Editorial-style home page and guide directory
- Cheat codes, missions, characters, vehicles, map and news sections
- Responsive, accessible, fast static website
- No paid hosting dependency for the initial release

## Deployment
The site is designed to be deployed as a static website on Cloudflare Pages. Domain and Worker/DNS settings are intentionally not changed by this repository setup.
